## 1. 本ツールについて

構造図 PDF と構造計算書 PDF をアップロードすると、各部材（小梁・スラブ）の符号・断面寸法・配筋を自動照合し、不整合を一覧表示します。

### 対応する計算書ソフト
- StructureSuite（複数の見出し書式）
- Union System Super Build／SS7
- Union System Super Build／ＲＣ２次部材

### 動作環境
- Windows PC（YHG.exe を実行）
- ブラウザは内蔵のため別途インストール不要

---

## 2. 基本操作

### 手順

1. **YHG.exe を起動** — ブラウザ画面が開きます
2. **構造図 PDF をアップロード** — 左側のドロップエリアにドラッグ＆ドロップ
   - 複数ファイル可（基礎梁リスト＋二次部材リスト等が別ファイルなら全てアップロード）
3. **計算書 PDF をアップロード** — 右側のドロップエリアに
   - 複数ファイル可（巻が分かれている場合は全てアップロード）
4. **「整合チェック実行」をクリック** — 20〜30秒で結果表示
5. **結果を確認** — 「PDFで照合」ボタンで該当箇所を並べて目視できます
6. **必要に応じて PDF レポートで出力**

## 3. ⚠ 重要：図面PDFの形式について

### 本ツールが扱える PDF
本ツールは PDF 内の **文字情報（テキストレイヤー）** を読み取ります。**以下の形式の PDF はご利用いただけません。**

| ❌ 利用不可な PDF | 理由 |
|---|---|
| スキャナで紙図面を読み取った PDF | 画像のみで文字情報なし |
| DocuWorks / CubePDF 経由で **SHX フォントの図面**を PDF 化したもの | SHX 文字がアウトライン化される |
| AutoCAD で **SHX フォント**を使用したまま PDF 出力したもの | SHX 文字は線図形として PDF 化される（次章参照）|

> ✅ **重要な例外**：AutoCAD の文字スタイルが **TrueType フォント**（MSゴシック・MS明朝・游ゴシック等）の場合は、
> - 直接 PDF 出力しても
> - **DocuWorks 経由で PDF 変換しても**
> - **CubePDF 経由で PDF 変換しても**
>
> いずれも**文字情報が保持されたまま PDF 化**されるため、本ツールでそのまま利用できます。
> 「DocuWorks 経由は使えない」のは**フォントが SHX の場合のみ**です。新規物件で TrueType を標準化していれば、CAD 出力経路を変える必要はありません。

### 簡単な判別方法

PDF を Adobe Acrobat や任意のブラウザで開き：

1. **`Ctrl+F`** で検索ボックスを開く
2. 図面内に書かれている**符号（"FG1" など）**を検索
3. **ヒットすれば** テキスト化されている ✓
4. **ヒットしなければ** 画像 PDF（利用不可）

または、図面内の文字をマウスでドラッグして**選択できれば OK**、できなければ NG。

### エラー時のツール動作
画像PDF をアップロードしてチェック実行した場合、結果画面の上部に黄色の警告カードが表示されます：

```
⚠ 構造図PDFから部材・スラブが1件も抽出できませんでした。
  ベクター化された竣工図など、文字情報を持たないPDFの可能性があります。
  テキスト埋め込み版の構造図PDFを使用するか、OCR処理後のPDFをご利用ください。
```

## 4. AutoCAD から検索可能 PDF を作成する手順

AutoCAD で作成した図面でも、**設定によってはテキスト情報が PDF に含まれません**。原因と対処法を説明します。

### 原因：SHX フォント

AutoCAD には2種類のフォントがあります：

| 形式 | 例 | PDF にしたとき |
|---|---|---|
| **SHX**（AutoCAD 固有） | `txt.shx`, `simplex.shx`, `extfont.shx`, `bigfont.shx` | **線図形に変換される → テキスト抽出不可** |
| **TrueType**（Windows標準） | `MSゴシック`, `MS明朝`, `游ゴシック`, `Arial` | 文字として埋め込まれる → **テキスト抽出可能** |

構造設計事務所では従来から **SHX フォント** で寸法・符号を書く慣習が強く、これが「AutoCAD から作った PDF なのに文字が選択できない」原因です。

### 使用中フォントの確認方法

AutoCAD のコマンドラインで：

```
STYLE
```

「文字スタイル管理」ダイアログが開きます。使用中のフォント名が **`.shx`** で終わる場合は SHX フォントです（要対処）。

---

### 解決策1：印刷時オプションで SHX を検索可能テキストとして埋め込む（最も簡単）

**この方法は既存の SHX 図面のままで対応できます。** AutoCAD 2016 以降で利用可能。

> ⚠ オプションの**場所は AutoCAD のバージョンにより異なります**。下記の **方法 A（推奨）** が最も確実です。

#### 方法 A：システム変数 `PDFSHX` を設定する（最も簡単・確実）

ダイアログを探す必要がなく、コマンドライン1回で済みます。

1. AutoCAD のコマンドライン（画面下）に入力：
   ```
   コマンド: PDFSHX
   PDFSHX に対する新しい値を入力 <0>: 1
   ```
   ※ AutoCAD 2024 以降は `2` も指定可能。**2021〜2023 では 0/1 のみ**。
2. その後、通常どおり `PLOT`（または `EXPORTPDF`）で PDF 出力 → SHX 文字が PDF コメント注釈として埋め込まれる
3. 本ツールは PDF コメント注釈もテキストとして取り込むので、整合チェックに使えます

| 値 | 動作 | 利用可能バージョン |
|---|---|---|
| **0** | SHX 文字は線図形のまま（**テキスト抽出不可**） | 全バージョン（既定値）|
| **1** | SHX 文字を **PDF コメント注釈**として埋め込み（**本ツールで読める**） | 2017 以降 |
| **2** | SHX 文字を**実テキスト**として埋め込み（理想形）| **2024 以降のみ** |

> AutoCAD 2021 を含むほとんどの環境では **`PDFSHX = 1` が最大設定**です。本ツール側でコメント注釈の読み取りに対応しているので、`1` で問題なく利用できます。

> 確認：`SETVAR` → `PDFSHX` で現在値を表示できます。AutoCAD を終了すると初期値に戻ることがあるため、運用ルールに含めるか、起動マクロに `PDFSHX 1` を入れておくと確実です。

#### 方法 B：`EXPORTPDF` コマンドのオプションから設定

新しい AutoCAD（2020 以降）では、PLOT ではなく **`EXPORTPDF`** コマンドを使うと専用ダイアログが出ます。

1. コマンドライン：`EXPORTPDF`（または **メニュー → エクスポート → PDF**）
2. 「PDF として保存」ダイアログ右下の **「PDF オプション」** ボタンをクリック
3. ☑ **「SHX テキストを検索可能テキストとして含める」**（"Include SHX text as comments" / "Capture fonts"）
4. ☑ **「TrueType テキストを検索可能テキストとして含める」**（任意）
5. OK → ファイル名指定 → 保存

#### 方法 C：PLOT ダイアログのカスタムプロパティから設定（旧バージョン）

AutoCAD 2017〜2019 頃の操作（**バージョンにより画面構成が異なる**ので注意）：

1. `Ctrl+P`（または `PLOT`）→ プリンタ：**`DWG to PDF.pc3`** を選択
2. **「プロパティ」** ボタン
3. **「デバイスとドキュメントの設定」** タブ → ツリー内の **「カスタムプロパティ」**
4. 下部の **「カスタムプロパティ」** ボタン
5. 出てくる「DWG To PDF プロパティ」ダイアログのタブ：
   - AutoCAD バージョンにより **「データ」** タブ、**「拡張」** タブ、または **「PDF」** タブ にあります
   - 旧バージョンでは **「一般」** タブ にありました
6. ☑ **「SHX テキストを検索可能テキストとして含める」** にチェック
7. OK → 構成変更を保存
8. 印刷を実行

> **「全般」タブに見当たらない場合は、他のタブを確認してください。** AutoCAD のバージョンや言語設定により場所が異なります。**方法 A の `PDFSHX` 変数が最も確実です**。

#### 確認方法

作成された PDF を Adobe Acrobat または Edge で開き、`Ctrl+F` で符号（例：`FG1`）を検索 → ヒットすれば成功。

> **注意**：「コメント注釈」（PDFSHX=1）として埋め込まれた SHX 文字は実テキストとは若干位置がずれる可能性があります。**`PDFSHX=2`**（実テキスト埋め込み）の方が本ツールでの抽出精度が高くなります。

---

### バージョン別の推奨ルート

| AutoCAD バージョン | 推奨ルート |
|---|---|
| 2017 〜 2023 | **方法 A（`PDFSHX 1`）** または 方法 B（EXPORTPDF）|
| 2024 以降 | **方法 A（`PDFSHX 2`）** が理想（実テキスト埋め込み）|
| AutoCAD LT 各バージョン | PDFSHX 非対応のことが多い → **解決策2（TrueType 置換）** を推奨 |

### 注意点：PDFSHX=1 と PDFSHX=2 の違い

- **PDFSHX=2**（実テキスト）：Adobe Acrobat の標準テキストとして埋め込まれ、コピー＆ペースト・検索・抽出すべて完璧
- **PDFSHX=1**（コメント注釈）：PDF の注釈レイヤーに埋め込まれる。Adobe Acrobat の検索ではヒットするが、文字の表示位置と注釈位置が**若干ずれる**ことがある

本ツールは PDFSHX=1 のコメント注釈にも対応していますが、注釈の位置精度が低い場合は配筋値の対応関係が不正確になる可能性があります。可能であれば **解決策2（TrueType フォントへの置換）が最も精度が高い**です。



---

### 解決策2：文字スタイルを TrueType フォントに置き換える（最も確実・恒久対処）

**新規物件・社内標準化におすすめ。** 図面を恒久的に検索可能 PDF として出力できるようになります。

#### 手順

1. AutoCAD でコマンド `STYLE` を実行
2. 「文字スタイル管理」ダイアログで使用中のスタイル（例：`Standard`, `DIM` 等）を選択
3. **「フォント名」** ドロップダウンから **`.shx`** フォントではなく **TrueType フォント** を選択
   - 推奨：`MS ゴシック`、`MS Pゴシック`、`游ゴシック`、`HG ゴシック`
4. **「適用」** → **「閉じる」**
5. 図面を再生成（`REGEN` コマンド）
6. PDF を出力

#### TrueType フォントを使うメリット

- **どの経路で PDF 化しても文字認識される**
  - AutoCAD 直接 PDF 出力（PLOT / EXPORTPDF）
  - **DocuWorks → PDF 変換**（社内で DocuWorks を介在させても可）
  - **CubePDF / Adobe PDF プリンタ等の汎用 PDF プリンタ**
- いずれの経路でも文字レイヤーが保持されるため、本ツールにそのままアップロードできる
- `PDFSHX` システム変数を意識する必要がない
- **PDF 上でテキスト選択・検索・コピー＆ペーストが可能**になり、図面の活用範囲が広がる

#### 注意点

- 文字スタイル変更により**文字の幅・行間が微妙に変わる**ことがあります。重要な図面では事前にプレビューで確認してください
- 既存大量物件への一括適用は慎重に。新規物件から段階的に切り替えることを推奨

---

### 解決策3：Bluebeam Revu 等の専用ツールを使用

社内に SHX 文字を含む既存図面が大量にあり、AutoCAD 標準の PDF 出力で問題が解決しない場合：

- **Bluebeam Revu**：構造系で人気の PDF 編集ツール。SHX 文字を正確にテキスト化可能
- **Adobe PDF Maker for AutoCAD**：Adobe Acrobat Pro のアドイン

---

### 推奨される社内運用ルール

| 場面 | 対応 |
|---|---|
| **新規物件** | CAD 標準を TrueType フォント（MSゴシック等）に統一（解決策2） |
| **既存物件で対応** | 印刷時に「SHX テキストを検索可能テキストとして含める」を ON（解決策1） |
| **第三者から受領** | 解決策1 を試す → ダメなら解決策2 でフォント置換 |
| **緊急対応** | Adobe Acrobat の「テキスト認識（OCR）」を実行 |

## 5. 検出結果の見方

### 種別と判定基準

| 種別 | 意味 | 推奨アクション |
|---|---|---|
| **一致** | 図面と計算書で符号・断面・配筋がすべて一致 | OK |
| **配筋不一致** | 配筋（主筋・あばら筋等）が異なる | 設計者確認 |
| **断面幅不一致** | B（幅）が異なる | 設計者確認 |
| **スラブ厚不一致** | スラブ厚が異なる | 設計者確認 |
| **スラブ配筋不一致** | スラブの配筋が異なる | 設計者確認 |
| **要目視確認** | 連梁等で自動判定不能 | 「PDFで照合」で目視 |
| **構造図のみ** | 図面にあるが計算書に無い | 計算範囲外か漏れか確認 |
| **計算書のみ** | 計算書にあるが図面に無い | 反映漏れの可能性 |

### フィルタ機能

- **基礎部材（FB/FCG/FG）を除外** — 基礎梁の差分を非表示
- **片持小梁（CB/WCB）を除外**
- **壁梁（WB）を除外**
- **種別ごとの表示/非表示切替**

### PDF レポート出力

「小梁をPDF出力」「スラブをPDF出力」で、差分箇所を PDF レポートとして保存できます。

- 各差分について **構造図と計算書を並べて表示**
- 該当箇所を**橙枠（部材全体）と赤枠（差分箇所）でハイライト**
- 元 PDF のページ番号を併記

## 6. 既知の制限事項

| 制限事項 | 対処方法 |
|---|---|
| 画像 PDF（テキストなし）の図面 | Adobe Acrobat の OCR 機能でテキスト化、または「§4 AutoCAD から検索可能 PDF を作成する手順」を参照 |
| 図面が複数ファイルに分割（基礎梁・二次部材等） | 関連 PDF をすべて図面欄にアップロード |
| 連梁（B3A 等、通り芯で配筋が変わる） | 「要目視確認」と判定。「PDFで照合」で目視 |
| FEM（有限要素法）で検討された不定形スラブ（S24 等） | 標準形式 `lx=...` ではないため自動検出対象外、計算書を目視確認 |
| 1m 幅梁として検討されたスラブ（屋上機械室等） | 計算書では梁の断面計算表で出力されるため自動検出対象外 |
| 同符号で複数断面（FB2 が 350×1400 と 450×1400 等）| ツールは最初の断面を採用。図面側で枝番（FB2a/FB2b）化を検討 |
| 配筋値の上書き注記（「※... 2/2-D16 とする」等） | ツール側で対応済み（自動で上書き値を採用） |
| 共通図面＋複数棟の計算書 | 全棟の計算書を計算書欄にアップロードすれば集約照合可能 |

## 7. トラブルシューティング

### Q1. 「構造図PDFから部材・スラブが1件も抽出できませんでした」と警告が出る

**原因**：PDF が画像形式または SHX フォントで作成されている可能性があります。

**対処**：「§3 重要：図面PDFの形式について」と「§4 AutoCAD から検索可能 PDF を作成する手順」をご確認ください。

### Q2. 大量の「計算書のみ」が出る

**原因**：基礎梁系（FB/FCG/FG）が計算書に含まれているが、図面にその基礎梁リストが含まれていない可能性。

**対処**：基礎梁リスト PDF を追加で図面欄にアップロード、または「基礎部材（FB/FCG/FG）を除外」フィルタを ON にして非表示にしてください。

### Q3. 「配筋不一致」が出るが、実際の図面と計算書を見比べると一致している

考えられる原因：
- **同符号で複数断面**を使い分けている（例：B2 が階によって 350×650 と 400×800）→ 図面側で枝番（B2a/B2b 等）化を検討
- **計算書の注記による上書き**を見落としている → 計算書本文に「※... とする」の記載があるか確認（ツールは検出対応済み）
- **配筋方向の解釈違い**（主筋方向と配力筋方向のスワップ）

「PDFで照合」ボタンで両者を並べて目視確認してください。

### Q4. PDF レポートを出力しようとすると「Internal Server Error」

修正済みです（旧バージョンでは Content-Disposition の日本語処理で発生していました）。最新の YHG.exe をご利用ください。

### Q5. 整合チェック実行が遅い（30秒以上かかる）

**原因**：計算書PDF のページ数が多い（50ページ超）、または複数の計算書ファイルを同時にアップロードした場合は処理に時間がかかります。

**対処**：通常 20〜60 秒で完了します。1分以上かかる場合は再起動してお試しください。

### Q6. 「PDFで照合」モーダルで画像が表示されない

**原因**：ブラウザのキャッシュまたは PDF アップロード直後に発生することがあります。

**対処**：
1. モーダルを閉じて再度開く
2. 改善しない場合：「すべて消去」→ ファイル再アップロード → 整合チェック再実行
