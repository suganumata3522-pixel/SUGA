# RC構造図・計算書 整合性確認ツール

ゼネコン構造設計部内で利用する、RC造マンションの構造図と計算書の整合性確認用Webツールです。

## 特徴

- **インストール不要**: `index.html` をブラウザで開くだけで動作
- **サーバ不要**: 全処理がブラウザ内で完結（PDFファイルは外部送信されません）
- **オフライン対応可**: PDF.jsをローカルに置けば社内ネット閉鎖環境でも使用可能

## 対応範囲（第一段階）

- 小梁（B, b, CB, RB系）
  - 断面寸法 (B×D)
  - 上端筋・下端筋
  - あばら筋 (STP)
- スラブ（S, FS, RS系）
  - 厚さ t
  - 短辺方向・長辺方向 × 上端・下端の配筋

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. 計算書PDFと構造図PDFをそれぞれドラッグ＆ドロップ
3. 「小梁」または「スラブ」タブを選択
4. 「整合性チェック実行」をクリック
5. 結果テーブルでOK/NG/要確認を確認、必要に応じてCSV出力

## 配布方法

`index.html` を社内共有フォルダに配置するか、各PCのデスクトップに置くだけで利用可能です。

## 注意事項

- テキストベースのPDFが対象です。スキャン画像のみのPDFはOCRが必要となり現バージョンでは未対応です。
- 抽出パターンは一般的な構造計算書・構造図の表記を想定しています。社内フォーマットに合わせて `index.html` 内の正規表現（`parseBeams` / `parseSlabs`）の調整が必要な場合があります。
- 社内ネットでCDN（cdnjs）が利用できない場合は、PDF.jsの `pdf.min.js` および `pdf.worker.min.js` をローカルに配置し、`<script>` タグのURLを書き換えてください。
